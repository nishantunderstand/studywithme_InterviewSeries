
🚀 Ditto Insurance Interview Experience | React.js | 6 YOE | Expected CTC: 21 LPA  
  
Preparing for a Frontend Developer interview? Here’s a recent interview experience at Ditto Insurance shared by a candidate, covering React.js, JavaScript, Next.js, state management, performance optimization, and more.  
  
💡 Interview Process:  
  
1. Initial Screening – Introductory discussion + screening (60 minutes)  
2. Technical Round 1 – Technical Lead (30 minutes)  
3. Virtual Technical Round – React.js, JavaScript & machine coding  
4. Onsite Technical Round – React.js, JavaScript & machine coding  
5. Final HR Round  
  
🔥 Key Technical Areas Covered:  
  
1️⃣ Project & Next.js  
  
* Explain Next.js and its features.  
* Discuss your recent project and the most complex problem you solved.  
* Experience building blockchain and analytics platforms.  
  
2️⃣ React & State Management  
  
* React Hooks and state management.  
* Redux vs Redux Toolkit.  
* Redux vs Zustand vs Context API.  
* How does TanStack Query work?  
* How does state management work in React?  
  
3️⃣ Performance Optimization  
  
* How do you optimize React applications?  
* How did you reduce LCP to around 2.5 seconds?  
* Code splitting, lazy loading and image optimization.  
* Explain LCP, INP and CLS.  
  
4️⃣ React Internals & Hooks  
  
* useMemo vs useCallback.  
* What is React.memo?  
* Can useCallback memoize a component?  
* Redux dispatch vs asynchronous operations.  
* What is Redux middleware?  
  
5️⃣ API Integration & Other Topics  
  
* How do you communicate with backend APIs?  
* Structuring Axios configuration and API calls.  
* Hooks beyond commonly used ones.  
* React form libraries.  
* Zod and schema validation.  
* What technical skills have you learned in the past year?  
  
📌 Interview Outcome: Rejected after Round 1.  
  
Key Takeaway: Understanding concepts deeply matters more than memorizing answers. Be prepared for follow-up questions, especially around React internals, hooks, Redux, and performance optimization.  
  
Every interview is an opportunity to learn, improve, and move forward. On to the next opportunity! 🚀
