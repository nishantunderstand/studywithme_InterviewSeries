🚀 TCS Agentic AI Engineer Interview Experience | LLM | RAG | LangGraph  
  
Preparing for an Agentic AI Engineer role? Here’s an interview experience covering LLM inference, optimization, RAG, model evaluation, and AI agents.  
  
🔹 Round 1: Technical Interview  
  
Key questions:  
  
* How do you develop an LLM inference microservice?  
* Explain KV caching and inference optimization.  
* How do you configure HPA for LLM services?  
* What are model quantization and distillation?  
* How do you handle LLM hallucinations and repetitive outputs?  
* How do you implement LLM-as-a-Judge?  
* How do you manage document versions in RAG?  
* How do you parse large tables from PDFs into RAG?  
* Micro F1 vs Macro F1.  
* How do you handle imbalanced datasets?  
  
🔹 Round 2: Technical & Project Discussion  
  
* Explain your project architecture.  
* Which latency metrics do you measure?  
* Which frameworks do you use for LLM deployment?  
* Build a working summarizer agent using LangGraph.  
  
💡 Key Takeaways  
  
* Understand LLM inference and serving deeply.  
* Prepare KV cache, batching, quantization, and optimization.  
* Strengthen RAG pipelines and document processing.  
* Learn evaluation techniques and hallucination handling.  
* Get hands-on experience building agents with LangGraph.  
  
🔥 Interview Tip: Don’t just learn LLM terminology. Be ready to explain implementation choices, performance trade-offs, and real-world use cases.
