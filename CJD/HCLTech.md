🚀 HCLTech Java Developer Interview Experience | Citi Bank | 4 Rounds  
  
Preparing for a Java Developer interview? Here’s a recent interview experience covering Core Java, DSA, SQL, Spring Boot, live coding, and debugging.  
  
🔹 Round 1: HackerEarth Assessment  
  
* 20 MCQs  
* 1 DSA coding question  
* 1 SQL query  
* Topics: Core Java, OOP, Collections, Multithreading, Exception Handling, and SQL.  
  
🔹 Round 2: Project-Based & AI Interview  
  
* Develop a Spring Boot application based on given requirements.  
* Create REST APIs using Controller, Service, and Repository layers.  
* Four AI-based video/voice questions on technical knowledge, projects, and problem-solving.  
  
🔹 Round 3: HCLTech Technical Interview (60 Minutes)  
  
* Project discussion and architecture.  
* Core Java fundamentals.  
* Live coding and debugging.  
* Implement 3+ methods in an existing codebase.  
* Validate logic against test cases.  
  
🔹 Round 4: Client Technical Interview – KARAT (60 Minutes)  
  
* Current project discussion.  
* Around 5 Core Java questions.  
* Live coding and debugging.  
* Implement 2–3 methods.  
* Explain approach, complexity, and edge cases.  
  
💡 Key Takeaways  
  
* Strengthen Core Java and Collections.  
* Practice DSA and SQL.  
* Build Spring Boot applications hands-on.  
* Practice debugging existing code.  
* Explain your approach, time complexity, and edge cases while coding.  
  
🔥 Important: Both technical rounds heavily focused on live coding, debugging, and explaining your implementation.
