Top 20 Java Failure-Scenario Interview Questions  
  
Senior Java interviews aren’t only about writing code. Interviewers often ask:  
  
“What happens when things fail in production?”  
  
Here are 20 scenarios worth preparing:  
  
1. What happens when a HashMap has many hash collisions?  
2. What if equals() and hashCode() are implemented incorrectly?  
3. How do you troubleshoot OutOfMemoryError?  
4. What causes StackOverflowError?  
5. How do you identify a Java memory leak?  
6. What happens when multiple threads update the same variable?  
7. How do you troubleshoot a race condition?  
8. How can a deadlock occur?  
9. What happens when a thread pool is exhausted?  
10. How do you troubleshoot high CPU usage?  
11. How do you investigate high GC activity?  
12. What happens when the database connection pool is exhausted?  
13. How do you troubleshoot a slow API?  
14. What happens when an external service goes down?  
15. How do you prevent cascading failures in microservices?  
16. What happens when Kafka consumers stop processing messages?  
17. How do you handle duplicate messages?  
18. What happens when a transaction partially succeeds?  
19. How do you troubleshoot intermittent production failures?  
20. Why might an application work locally but fail in production?  
  
For every scenario, prepare your answer using:  
  
Symptoms → Root Cause → Investigation → Fix → Prevention → Monitoring
