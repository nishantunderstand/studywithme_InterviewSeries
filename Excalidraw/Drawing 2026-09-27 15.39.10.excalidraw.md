Core components:
- API Gateway: Authentication, rate limiting, routing.
- Transfer Service: Validates requests and creates transfer records.
- Account/Ledger Service: Performs balance updates and maintains immutable ledger entries.
- Kafka: Asynchronous event distribution and workload buffering.
- Transactional Outbox: Ensures committed database changes are reliably published to Kafka.
- Redis: Optional caching for non-authoritative data, never the source of truth for balances.
